Manual de AnimeNotepad

Guía rápida para AnimeNotepad 2.3.0.

Funciones Básicas

  • Nuevo: Crea un documento en blanco.
  • Abrir: Carga un archivo de texto o una nota cifrada .uwu.
  • Guardar: Guarda el contenido actual en texto plano o vuelve a cifrar una nota .uwu.
  • Guardar como: Permite elegir entre un archivo de texto .txt y un archivo cifrado .uwu.

Notas cifradas .uwu

El formato .uwu protege el contenido mediante AES-GCM y una contraseña. Para crear una nota cifrada, usa Archivo > Guardar como..., elige Archivo cifrado (*.uwu) y escribe una contraseña.

Para abrirla, selecciona Archivo > Abrir... o haz doble clic en el archivo desde el sistema operativo. AnimeNotepad solicitará la contraseña antes de mostrar el contenido.

Mientras la nota cifrada permanece abierta, puedes editarla y usar Guardar normalmente. La contraseña se conserva únicamente en memoria durante esa sesión y no se almacena dentro del archivo. Si la olvidas, la nota no se puede recuperar.

Archivos asociados

Las versiones instaladas registran la extensión .uwu para que el sistema operativo la abra con AnimeNotepad mediante doble clic o desde el menú contextual.

Atajos de Teclado

  • Ctrl + N: Nuevo archivo
  • Ctrl + S: Guardar
  • Ctrl + O: Abrir archivo
  • Ctrl + Shift + S: Guardar como
  • Ctrl + Z: Deshacer
  • Ctrl + Y: Rehacer
